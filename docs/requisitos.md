# Documento de Requisitos

## 1. Nome do Projeto

UniManager

## 2. Objetivo

O UniManager é um sistema web para gerenciamento acadêmico, desenvolvido para auxiliar administradores e professores no controle de alunos, disciplinas, matrículas, notas e frequência.

O sistema será desenvolvido utilizando Python, Flask, SQLAlchemy e SQLite, seguindo boas práticas de desenvolvimento de software.

## 3. Usuários do Sistema

### Administrador

- Gerenciar alunos
- Gerenciar professores
- Gerenciar disciplinas
- Gerenciar cursos
- Gerenciar turmas
- Visualizar dashboard

### Professor

- Visualizar alunos
- Lançar notas
- Registrar frequência
- Visualizar disciplinas

## 4. Funcionalidades

### Autenticação

- Login
- Logout
- Cadastro de usuário
- Recuperação de senha (simulada)

### Dashboard

- Total de alunos
- Total de professores
- Total de disciplinas
- Média geral
- Próximas avaliações

### Alunos

- Cadastrar
- Editar
- Excluir
- Pesquisar

### Professores

- Cadastrar
- Editar
- Excluir
- Pesquisar

### Disciplinas

- Cadastrar
- Editar
- Excluir

### Matrículas

- Matricular aluno
- Cancelar matrícula

### Notas

- Lançar notas
- Calcular média automaticamente
- Situação do aluno

### Frequência

- Registrar presença
- Registrar falta
- Calcular percentual de frequência

## 5. Tecnologias

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap
- Git
- GitHub

## 6. Objetivo do Projeto

Desenvolver um sistema web organizado, escalável e com arquitetura profissional, servindo como projeto de portfólio para demonstrar conhecimentos em desenvolvimento back-end, banco de dados, controle de versão e boas práticas de engenharia de software.
